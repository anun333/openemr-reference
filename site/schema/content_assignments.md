# `content_assignments`

As OpenEMR 8.5.0's `sql/database.sql` creates it. Engine InnoDB.

## Columns

| Column | Type | Null | Default | Extra | Comment |
|---|---|---|---|---|---|
| `id` | `bigint(21) unsigned` | no |  | auto_increment |  |
| `resource_type` | `varchar(63)` | no | `'questionnaire'` |  | what is being assigned. A resource belongs here when "may this appear on this surface, in this context" is answered by the columns below; content scoped by patient cohort or carrying a send schedule does not |
