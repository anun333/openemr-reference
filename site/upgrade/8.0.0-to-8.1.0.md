# Upgrading OpenEMR 8.0.0 to 8.1.0

What changes between `v8_0_0` (2026-02-09) and `v8_1_0` (2026-06-01) that matters before and after an upgrade. The upgrade steps themselves are on the OpenEMR wiki; new features are in the wiki's [Release Features](https://www.open-emr.org/wiki/index.php/Release_Features).

## Before you upgrade

- **New PHP extensions required:** `redis`.
- **Node requirement:** none → `>=24.0.0`.
- **CI no longer tests:** MariaDB 12.0. If your database is one of these, check it is still supported before upgrading.
- **CI now also tests:** MariaDB 12.2.
- **Databases CI tested:** 8.0.0: MariaDB 10.6, 10.11, 11.4, 11.8, 12.0; MySQL 5.7, 8.0, 8.4, 9.3 (PHP 8.2, 8.3, 8.4, 8.5, 8.6). 8.1.0: MariaDB 10.6, 10.11, 11.4, 11.8, 12.2; MySQL 5.7, 8.0, 8.4, 9.3 (PHP 8.2, 8.3, 8.4, 8.5, 8.6).

## Settings (Administration > Config)

**New:**

- `main_menu_logo_link` (Branding): Main menu logo link URL. Default `https://www.open-emr.org/`.
- `main_menu_logo_title` (Branding): Main menu logo link title. Default none.
- `rainforest_api_key` (Connectors): Rainforest API Key. Default none.
- `rainforest_merchant_id` (Connectors): Rainforest Merchant ID. Default none.
- `rainforest_platform_id` (Connectors): Rainforest Platform ID. Default none.
- `rainforest_webhook_secret` (Connectors): Rainforest Webhook Secret. Default none.

**Removed:**

- `allow_multiple_databases` (Security): Allow multiple databases
- `enable_amc_tracking` (CDR): Enable AMC Tracking
- `gbl_nav_visit_forms` (Appearance): Navigation Area Visit Forms
- `machine_name` (Branding): Application Machine Name
- `safe_key_database` (Security): Safe key database

**Changed:**

- `payment_gateway`: choices added ['Rainforest'], removed []
