# Upgrading OpenEMR 8.1.0 to 8.2.0

What changes between `v8_1_0` (2026-06-01) and `v8_2_0` (2026-07-08) that matters before and after an upgrade. The upgrade steps themselves are on the OpenEMR wiki; new features are in the wiki's [Release Features](https://www.open-emr.org/wiki/index.php/Release_Features).

## Before you upgrade

- No change in the PHP version, PHP extensions or Node requirement.
- **Databases CI tested:** 8.1.0: MariaDB 10.6, 10.11, 11.4, 11.8, 12.2; MySQL 5.7, 8.0, 8.4, 9.3 (PHP 8.2, 8.3, 8.4, 8.5, 8.6). 8.2.0: MariaDB 10.6, 10.11, 11.4, 11.8, 12.2; MySQL 5.7, 8.0, 8.4, 9.3 (PHP 8.2, 8.3, 8.4, 8.5, 8.6).

## Database

- Database version 538 → 541.
- `sql_upgrade.php` runs, from 8.1.0: `sql/8_1_0-to-8_1_1_upgrade.sql`, `sql/8_1_1-to-8_2_0_upgrade.sql`.

No schema change.

## Settings (Administration > Config)

**New:**

- `database_encryption` (Features): Enable Encryption of Data Stored in the Database (Keep on unless DB server is encrypted). Default `1`.
- `user_php_debug` (Logging): User Debug PHP Reporting Options. Default `0`.
- `view_only_portal_appointments` (Portal): Allow Online Appointments View Only.. Default `0`.

**Removed:**

- `certificate_authority_crt` (Security): Path to CA Certificate File
- `certificate_authority_key` (Security): Path to CA Key File
- `client_certificate_valid_in_days` (Security): Client Certificate Expiration Days
- `enable_auditlog_encryption` (Logging): Enable Audit Log Encryption
- `is_client_ssl_enabled` (Security): Enable Client SSL

**Changed:**

- `user_debug`: type `select` → `bool`
