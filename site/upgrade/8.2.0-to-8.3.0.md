# Upgrading OpenEMR 8.2.0 to 8.3.0

What changes between `v8_2_0` (2026-07-08) and `v8_3_0` (2026-08-18) that matters before and after an upgrade. The upgrade steps themselves are on the OpenEMR wiki; new features are in the wiki's [Release Features](https://www.open-emr.org/wiki/index.php/Release_Features).

## Before you upgrade

- **PHP must be 8.3.0 or later** (was 8.2.0). Upgrade PHP first.
- **Databases CI tested:** 8.2.0: MariaDB 10.6, 10.11, 11.4, 11.8, 12.2; MySQL 5.7, 8.0, 8.4, 9.3 (PHP 8.2, 8.3, 8.4, 8.5, 8.6). 8.3.0: MariaDB 10.6, 10.11, 11.4, 11.8, 12.2; MySQL 5.7, 8.0, 8.4, 9.3 (PHP 8.3, 8.4, 8.5, 8.6).

## Database

- Database version 541 → 541.
- `sql_upgrade.php` runs, from 8.2.0: `sql/8_2_0-to-8_3_0_upgrade.sql`.

No schema change.

## Modules

No change.

## Settings (Administration > Config)

**New:**

- `smart_context_test_launches` (Connectors): Enable OpenEMR SMART ON FHIR Context Test Launches (Turn on only if you know what you are doing). Default `0`.

**Removed:**

- `audit_events_backup` (Logging): Audit Logging Backups
- `configuration_import_export` (Features): Configuration Export/Import
- `mysql_bin_dir` (Miscellaneous): Path to MySQL Binaries
- `perl_bin_dir` (Miscellaneous): Path to Perl Binaries

**Changed:**

- `questionnaire_display_LOINCnote`: default `0` → `3`
- `questionnaire_display_style`: choices added [], removed ['1']
