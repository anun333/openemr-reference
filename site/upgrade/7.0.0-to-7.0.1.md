# Upgrading OpenEMR 7.0.0 to 7.0.1

What changes between `v7_0_0` (2022-07-18) and `v7_0_1` (2023-04-25) that matters before and after an upgrade. The upgrade steps themselves are on the OpenEMR wiki; new features are in the wiki's [Release Features](https://www.open-emr.org/wiki/index.php/Release_Features).

## Before you upgrade

- **PHP must be 8.0.0 or later** (was 7.4.0). Upgrade PHP first.
- **CI no longer tests:** MariaDB 10.7. If your database is one of these, check it is still supported before upgrading.
- **CI now also tests:** MariaDB 10.9, MariaDB 10.10, MariaDB 10.11.
- **Databases CI tested:** 7.0.0: MariaDB 10.3, 10.4, 10.5, 10.6, 10.7, 10.8; MySQL 5.7, 8 (PHP 7.4, 8.0, 8.1, 8.2). 7.0.1: MariaDB 10.3, 10.4, 10.5, 10.6, 10.8, 10.9, 10.10, 10.11; MySQL 5.7, 8 (PHP 8.0, 8.1, 8.2, 8.3).

## Settings (Administration > Config)

**New:**

- `ccda_validation_disable` (Connectors): Disable All import CDA Validation Reporting. Default `0`.
- `display_acknowledgements_on_login` (Login Page): Display links to the acknowledgements page. Default `1`.
- `enable_swap_secondary_insurance` (Billing): Enable Swap Secondary Insurance Editing Demographics. Default `0`.
- `gbl_vitals_max_history_cols` (Appearance): Vitals Form Max Historical Columns To Display. Default `2`.
- `graph_data_warning` (Features): Graphing Data Warning. Default `0`.
- `oauth_app_manual_approval` (Connectors): OAuth2 App Manual Approval Settings. Default `0`.
- `secondary_logo_position` (Login Page): Order of the Secondary logo. Default `second`.
- `set_service_facility_encounter` (Encounter Form): Set Service Facility in Encounter. Default `0`.

**Changed:**

- `allow_debug_language`: default `0` → `1`
- `extra_logo_login`: moved to section `Branding` → `Login Page`
- `login_page_layout`: default `center` → `login/layouts/vertical_band.html.twig`
- `login_page_layout`: moved to section `Appearance` → `Login Page`
- `login_page_layout`: choices added ['login/layouts/horizontal_band_left_logo.html.twig', 'login/layouts/horizontal_band_right_logo.html.twig', 'login/layouts/horizontal_box_left_logo.html.twig', 'login/layouts/horizontal_box_right_logo.html.twig', 'login/layouts/vertical_band.html.twig', 'login/layouts/vertical_box.html.twig'], removed ['center', 'left', 'right']
- `login_tagline_text`: moved to section `Branding` → `Login Page`
- `show_label_login`: moved to section `Branding` → `Login Page`
- `show_labels_on_login_form`: moved to section `Branding` → `Login Page`
