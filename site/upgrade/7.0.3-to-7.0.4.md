# Upgrading OpenEMR 7.0.3 to 7.0.4

What changes between `v7_0_3` (2025-03-19) and `v7_0_4` (2025-12-18) that matters before and after an upgrade. The upgrade steps themselves are on the OpenEMR wiki; new features are in the wiki's [Release Features](https://www.open-emr.org/wiki/index.php/Release_Features).

## Before you upgrade

- **PHP must be 8.2.0 or later** (was 8.1.0). Upgrade PHP first.
- **PHP 8.2 removed:** 1 ini setting (`mysqli.reconnect`). It deprecates 2 more functions, which still work with a warning.
- Check this site's own code for these before moving PHP: `php scan.php --facts=php-changes.json --php=8.1:8.2 PATH` (the pre-flight check and `openemr-upgrade.sh` do it for the files a site added and its changes). From [php-upgrade-catalogue](https://github.com/anun333/php-upgrade-catalogue) 0.1.0, which covers PHP up to 8.5.
- **New PHP extensions required:** `bcmath`, `calendar`, `ctype`, `curl`, `dom`, `fileinfo`, `filter`, `gd`, `iconv`, `imagick`, `intl`, `json`, `ldap`, `libxml`, `mbstring`, `mysqli`, `openssl`, `pdo`, `pdo_mysql`, `phar`, `session`, `simplexml`, `soap`, `sockets`, `sodium`, `tokenizer`, `xml`, `xmlreader`, `xmlwriter`, `xsl`, `zip`, `zlib`.
- **CI no longer tests:** MariaDB 10.5, MariaDB 11.6. If your database is one of these, check it is still supported before upgrading.
- **CI now also tests:** MariaDB 11.8, MariaDB 12.0, MySQL 9.3.
- **Databases CI tested:** 7.0.3: MariaDB 10.5, 10.6, 10.11, 11.4, 11.6; MySQL 5.7, 8.0, 8.4 (PHP 8.1, 8.2, 8.3, 8.4, 8.5). 7.0.4: MariaDB 10.6, 10.11, 11.4, 11.8, 12.0; MySQL 5.7, 8.0, 8.4, 9.3 (PHP 8.2, 8.3, 8.4, 8.5, 8.6).

## Settings (Administration > Config)

**New:**

- `audit_events_http-request` (Logging): Audit Logging user page history.. Default `1`.
- `audit_events_lab-results` (Logging): Audit Logging Lab Results. Default `1`.
- `fhir_us_core_profile_version` (Connectors): Maximum supported version for US Core FHIR Implementation Guide -- note if a resource/profile is forwards compatible it will still be supported. Default `8.0.0`.
- `usps_apiv3_client_id` (Connectors): USPS API Client ID. Default none.
- `usps_apiv3_client_secret` (Connectors): USPS API Client Secret. Default none.

**Removed:**

- `menu_styling_vertical` (Appearance): Vertical Menu Style for Frames
- `usps_webtools_enable` (Connectors): Enable USPS Web Tools API
- `usps_webtools_username` (Connectors): USPS Web Tools API Username

**Changed:**

- `calendar_appt_style`: choices added ['5'], removed []
- `erx_newcrop_path`: default `https://secure.newcropaccounts.com/InterfaceV7/RxEntry.aspx` → `https://secure.newcropaccounts.com/ux2/InterfaceV7/RxEntry.aspx`
