# Upgrading OpenEMR 7.0.1 to 7.0.2

What changes between `v7_0_1` (2023-04-25) and `v7_0_2` (2023-11-15) that matters before and after an upgrade. The upgrade steps themselves are on the OpenEMR wiki; new features are in the wiki's [Release Features](https://www.open-emr.org/wiki/index.php/Release_Features).

## Before you upgrade

- **PHP must be 8.1.0 or later** (was 8.0.0). Upgrade PHP first.
- **CI no longer tests:** MariaDB 10.3, MariaDB 10.8, MariaDB 10.9, MySQL 8. If your database is one of these, check it is still supported before upgrading.
- **CI now also tests:** MariaDB 11.0, MariaDB 11.1, MySQL 8.0, MySQL 8.2.
- **Databases CI tested:** 7.0.1: MariaDB 10.3, 10.4, 10.5, 10.6, 10.8, 10.9, 10.10, 10.11; MySQL 5.7, 8 (PHP 8.0, 8.1, 8.2, 8.3). 7.0.2: MariaDB 10.4, 10.5, 10.6, 10.10, 10.11, 11.0, 11.1; MySQL 5.7, 8.0, 8.2 (PHP 8.1, 8.2, 8.3).

## Settings (Administration > Config)

**New:**

- `enable_eligibility_requests` (Insurance): Enable Insurance Eligibility. Default `0`.
- `enc_in_collection` (Encounter Form): Show In Collection on Encounter Form. Default set at run time: `RenderFormFieldHelper::SHOW_ALL`.
- `ip_max_failed_logins` (Security): Maximum Failed Login Attempts From IP Address. Default `100`.
- `ip_time_reset_password_max_failed_logins` (Security): Time (seconds) to Reset Maximum Failed Login Attempts From IP Address. Default `3600`.
- `logo_position` (Login Page): Logo Positioning. Default `flex-column`.
- `oauth_ehr_launch_authorization_flow_skip` (Connectors): OAuth2 EHR-Launch Authorization Flow Skip Enable App Setting. Default `0`.
- `portal_css_header` (Portal): Portal Default Theme. Default `style_light.css`.
- `portal_force_credential_reset` (Portal): Portal Login Forced Credential Reset. Default `0`.
- `portal_primary_menu_logo_height` (Portal): Primary Menu Logo Height. Default `30`.
- `primary_logo_width` (Login Page): Width of primary logo compared to the container. Default `w-50`.
- `recent_patient_count` (Appearance): Maximum number of patients on Recent Patient list. Default `20`.
- `secondary_logo_width` (Login Page): Width of secondary logo compared to the container. Default `w-50`.
- `show_primary_logo` (Login Page): Show primary logo on login. Default `1`.
- `time_reset_password_max_failed_logins` (Security): Time (seconds) to Reset Maximum Failed Login Attempts For User. Default `3600`.

**Removed:**

- `default_second_tab` (Appearance): Default Second Tab
- `default_top_pane` (Appearance): Main Top Pane Screen(Or Default First Tab)
- `enable_oa` (Insurance): Enable Office Ally Insurance Eligibility
- `gbl_nav_area_width` (Appearance): Navigation Area Width for Frames
- `gbl_tall_nav_area` (Appearance): Tall Navigation Area

**Changed:**

- `allow_debug_language`: default `1` → `0`
- `password_max_failed_logins`: default `0` → `20`
