# Upgrading OpenEMR 7.0.4 to 8.0.0

What changes between `v7_0_4` (2025-12-18) and `v8_0_0` (2026-02-09) that matters before and after an upgrade. The upgrade steps themselves are on the OpenEMR wiki; new features are in the wiki's [Release Features](https://www.open-emr.org/wiki/index.php/Release_Features).

## Before you upgrade

- No change in the PHP version, PHP extensions or Node requirement.
- **Databases CI tested:** 7.0.4: MariaDB 10.6, 10.11, 11.4, 11.8, 12.0; MySQL 5.7, 8.0, 8.4, 9.3 (PHP 8.2, 8.3, 8.4, 8.5, 8.6). 8.0.0: MariaDB 10.6, 10.11, 11.4, 11.8, 12.0; MySQL 5.7, 8.0, 8.4, 9.3 (PHP 8.2, 8.3, 8.4, 8.5, 8.6).

## Database

- `sql_upgrade.php` runs, from 7.0.4: `sql/7_0_4-to-8_0_0_upgrade.sql`.

## Settings (Administration > Config)

**New:**

- `disable_translation` (Locale): Disable Translation Engine. Default `0`.
- `translation_preload_cache` (Locale): Preload Translation Cache. Default `0`.

**Changed:**

- `cqm_performance_period`: default `2022` → `2025`
