# Upgrading OpenEMR 7.0.2 to 7.0.3

What changes between `v7_0_2` (2023-11-15) and `v7_0_3` (2025-03-19) that matters before and after an upgrade. The upgrade steps themselves are on the OpenEMR wiki; new features are in the wiki's [Release Features](https://www.open-emr.org/wiki/index.php/Release_Features).

## Before you upgrade

- No change in the PHP version, PHP extensions or Node requirement.
- **CI no longer tests:** MariaDB 10.4, MariaDB 10.10, MariaDB 11.0, MariaDB 11.1, MySQL 8.2. If your database is one of these, check it is still supported before upgrading.
- **CI now also tests:** MariaDB 11.4, MariaDB 11.6, MySQL 8.4.
- **Databases CI tested:** 7.0.2: MariaDB 10.4, 10.5, 10.6, 10.10, 10.11, 11.0, 11.1; MySQL 5.7, 8.0, 8.2 (PHP 8.1, 8.2, 8.3). 7.0.3: MariaDB 10.5, 10.6, 10.11, 11.4, 11.6; MySQL 5.7, 8.0, 8.4 (PHP 8.1, 8.2, 8.3, 8.4, 8.5).

## Settings (Administration > Config)

**New:**

- `add_unmatched_code_from_ins_co_era_to_billing` (Billing): Enable adding unmatched code from insurance company to billing table. Default `0`.
- `allow_custom_report` (Portal): Allow Online Custom Content Report. Default `1`.
- `allow_portal_uploads` (Portal): Allow Patient Uploads from Portal Documents. Default `1`.
- `auto_create_prevent_reason` (Calendar): Prevent Appointment Comment as Visit Reason. Default `0`.
- `enc_enable_ordering_provider` (Encounter Form): Show Ordering Provider option on Encounters. Default set at run time: `RenderFormFieldHelper::HIDE_ALL`.
- `extra_portal_logo_login` (Portal): Show Secondary Logo on portal Login page. Default `0`.
- `form_actionbar_position` (Appearance): Form ActionBar (save, cancel, etc) position. Default set at run time: `FormActionBarSettings::getDefaultSetting()`.
- `hide_dashboard_cards` (Appearance): Hide selected cards on patient dashboard. Default none.
- `pdf_font_size` (PDF): PDF Font Size in Pt. Default `10`.
- `questionnaire_display_LOINCnote` (Questionnaires): Display LOINC note on questionnaires. Default `0`.
- `questionnaire_display_fullscreen` (Questionnaires): Turn off full screen display for Questionnaire Forms. Default `0`.
- `questionnaire_display_style` (Questionnaires): Questionnaire Form Display Style. Default `0`.
- `rx_send_email` (Rx): Allow email sending of prescriptions. Default `1`.
- `secondary_portal_logo_position` (Portal): Order of the Secondary logo. Default `second`.
- `show_insurance_in_profile` (Portal): Allow Insurances in Patient Profile. Default `1`.
- `show_portal_primary_logo` (Portal): Show Primary Logo on portal login page. Default `1`.
- `use_email_for_portal_username` (Portal): Use Patients on-record E-Mail for new Portal Login Username. Default `1`.

**Removed:**

- `allow_portal_chat` (Portal): Allow Online Secure Chat
- `weno_encryption_key` (Connectors): Weno Encryption Key
- `weno_provider_password` (Connectors): Weno Provider Account Password
- `weno_rx_enable` (Connectors): Enable Weno eRx Service
- `weno_rx_enable_test` (Connectors): Enable Weno eRx Service Test mode

**Changed:**

- `oauth_ehr_launch_authorization_flow_skip`: default `0` → `1`
