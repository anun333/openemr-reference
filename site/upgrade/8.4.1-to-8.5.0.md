# Upgrading OpenEMR 8.4.1 to 8.5.0

What changes between `v8_4_1` (2026-09-20) and `v8_5_0` (2026-10-27) that matters before and after an upgrade. The upgrade steps themselves are on the OpenEMR wiki; new features are in the wiki's [Release Features](https://www.open-emr.org/wiki/index.php/Release_Features).

## Before you upgrade

- No change in the PHP version, PHP extensions or Node requirement.
- **Databases CI tested:** 8.4.1: MariaDB 10.11, 11.4, 11.8, 12.3; MySQL 8.4, 9.3 (PHP 8.3, 8.4, 8.5, 8.6). 8.5.0: MariaDB 10.11, 11.4, 11.8, 12.3; MySQL 8.4, 9.3 (PHP 8.3, 8.4, 8.5, 8.6, 8.7).

## Settings (Administration > Config)

**New:**

- `clear_ip_counter_on_auth_success` (Security): Clear IP Failed-Login Counter on Successful Authentication. Default `1`.
- `fee_sheet_save_appt_status` (Billing): Fee Sheet Save: Ask to Set Appointment Status. Default none.
- `medex_cancelled_apptstatus` (Connectors): MedEx Cancelled Appointment Statuses. Default `%;x`.
- `pdf_allowed_host` (Portal): Patient Portal PDF Renderer Allowed Host. Default none.
